# FvNeo

キーボード操作を中心にした、タブ式のファイル管理ソフト（Windows 用）です。

> このリポジトリは、配布と不具合報告のためのものです。ソースコードは公開していません。

## 主な特長

- **タブ式**：フォルダごとにタブで開き、タブグループとして保存・再開できます。ウィンドウの位置と開いていたタブは、次回起動時に復元されます。
- **1キーでの操作**：コピー（`C`）、移動（`M`）、削除（`D`）、名前の変更（`R`）、検索（`F`）、フィルタ（`W`）など。割り当ては変更できます。
- **ネットワークに強い**：読み込み・コピー・容量計算は別スレッドで動き、相手が応答しなくても他の操作を続けられます。数万件のフォルダも速く表示します。
- **書庫**：ZIP・TAR を内蔵で扱い、WinRAR があれば rar・7z などにも対応します。書庫ビューアで中身を見ながら解凍できます。
- **エディタ内蔵**：文字コードを自動判定するテキストエディタと、バイナリエディタを備えています。
- **フォルダの同期**、ファイルの分割・連結、ハッシュ計算、名前の一括置換 など。

使い方は、アプリの［ヘルプ］－［目次］をご覧ください。

## 動作環境

- Windows 10 以降の 64 ビット版（動作確認は Windows 11）
- .NET のインストールは不要です（同梱しています）。
- 書庫の rar・7z などを扱うには WinRAR が必要です（任意。同梱していません）。

## インストール

1. [Releases](https://github.com/agustaf4s/FvNeo/releases) から、最新の `FvNeo-Setup-x.xx.exe` をダウンロードします。
2. 実行して、画面の案内に従います。管理者権限は不要です。既定のインストール先は `%LocalAppData%\Programs\FvNeo` です。
3. スタートメニューの「FvNeo」から起動します。

アンインストールは、Windows の「インストールされているアプリ」から行います。設定は `%APPDATA%\FvNeo` に保存されており、アンインストールしても残ります。不要なら、手で削除してください。

## 不具合・要望・感想

アプリの［ヘルプ］から、［不具合を報告］［要望を送る］［感想・使用感を送る］を選ぶと、日本語の案内のあと、GitHub の入力画面が開きます。または [Issues](https://github.com/agustaf4s/FvNeo/issues) から直接お送りください。

- 送るには GitHub のアカウント（無料）が必要です。持っていなければ、ログイン画面の「Create an account」から作れます。
- 画面のボタンなどは英語ですが、入力欄には日本語の見出しがついていて、日本語で書き込めます。書き終えたら、緑のボタン「Submit new issue」を押すと送信されます。
- 不具合は、再現する手順、FvNeo のバージョン、Windows のバージョンを書いていただけると助かります（［不具合を報告］から開くと、バージョンは入力済みです）。
- 要望は、機能の名前より「何をしようとして何に困ったか」を書いていただくと伝わりやすくなります。ほかのファイラーに同じ機能があるなら、そこでの動きも書いてください（他のソフトの画面キャプチャは貼らないでください）。

FvNeo は、ログなどを自動では送信しません。ログ（`%APPDATA%\FvNeo\fvneo.log`）にはフォルダ名などの個人的な情報が含まれることがあります。添付する場合は、内容を確認してからにしてください。フォルダ名やファイル名は伏せてください。
